## Automatic Tree Sync

### What is Automatic Sync?

The platform automatically keeps your tree data synchronized with Antugrow AI, ensuring you always have the latest health and growth information without any manual effort.

**Status**: ✅ FULLY OPERATIONAL

### How It Works

#### Background Sync

**Automatic Updates**:
- Runs every 60 minutes automatically
- Syncs all your trees with Antugrow
- Updates height, diameter, and health status
- Happens in the background while you use the platform

**What Gets Synced**:
- Current height measurements
- Current diameter measurements
- Health status (healthy, stressed, diseased, dead)
- Growth data and trends
- Latest analysis results

#### Real-Time Updates

**Instant Notifications**:
- When Antugrow completes analyzing your tree photos
- When health issues are detected
- When measurements are updated
- When care recommendations change

**Webhook Events**:
- Analysis completed → Instant update
- Tree measurements updated → Instant update
- Health alert detected → Instant notification

### Sync Status Indicator

#### Where to Find It

The sync status indicator appears in the tree registry and tree details pages, showing you the current sync status.

#### What It Shows

**Compact View** (Small Button):
- 🔄 Syncing... (blue, animated)
- ✅ Synced (green)
- ⚠️ Errors (yellow)
- Last sync time (hover tooltip)

**Detailed View** (Full Panel):
- Last sync timestamp
- Number of trees synced
- Error count (if any)
- Progress bar during sync
- Manual sync button

#### Manual Sync

**When to Use**:
- You want to check for updates immediately
- You just uploaded new photos
- You want to ensure data is current

**How to Trigger**:
1. Click the sync button in the status indicator
2. Wait for sync to complete (usually < 30 seconds)
3. See updated data in your tree details

### Understanding Sync Status

#### Status Colors

**Green (✅)**:
- All trees synced successfully
- No errors
- Data is current

**Blue (🔄)**:
- Sync in progress
- Please wait
- Data updating

**Yellow (⚠️)**:
- Sync completed with some errors
- Most trees updated
- Check error details

#### Sync Timing

**Automatic Sync**:
- Every 60 minutes
- Starts automatically when you log in
- Continues in background
- Stops when you log out

**Manual Sync**:
- Instant when you click sync button
- Takes 10-30 seconds typically
- Updates all your trees
- Shows progress in real-time

### Troubleshooting Sync Issues

#### Sync Not Working?

**Check These**:
1. Are you logged in?
2. Do your trees have Antugrow IDs?
3. Is your internet connection stable?
4. Are there any error messages?

**Solutions**:
- Try manual sync
- Refresh the page
- Check sync status indicator
- Contact support if issues persist

#### Sync Taking Too Long?

**Normal Sync Times**:
- 1-10 trees: < 10 seconds
- 10-50 trees: 10-20 seconds
- 50-100 trees: 20-30 seconds
- 100+ trees: 30-60 seconds

**If It's Slower**:
- Check your internet speed
- Wait for current sync to complete
- Try again in a few minutes
- Contact support if persistent

#### Data Not Updating?

**Possible Reasons**:
- Antugrow hasn't analyzed yet
- Sync hasn't run recently
- Tree doesn't have Antugrow ID
- Network issues

**What to Do**:
1. Check if tree is registered with Antugrow
2. Trigger manual sync
3. Wait for next automatic sync
4. Check sync status for errors

### Automatic Sync (NEW)

**Q: How often does automatic sync run?**  
A: Automatic sync runs every 60 minutes (1 hour) in the background. You can also trigger manual sync anytime.

**Q: Do I need to do anything for sync to work?**  
A: No! Sync happens automatically in the background. Just make sure you're logged in and have trees registered with Antugrow.

**Q: What happens if I'm offline?**  
A: Sync will pause while you're offline and resume automatically when you're back online. No data is lost.

**Q: Can I change the sync frequency?**  
A: Currently, sync runs every 60 minutes. This frequency is optimized for data freshness and API usage. Custom intervals may be available in the future.

**Q: What if sync fails?**  
A: If sync fails for a tree, it will retry on the next sync cycle. The sync status indicator will show any errors. Most issues resolve automatically.

**Q: How do I know if my trees are synced?**  
A: Check the sync status indicator in the tree registry or tree details page. It shows the last sync time and status.

**Q: What are webhooks?**  
A: Webhooks are instant notifications from Antugrow when something happens (like analysis completion). They provide real-time updates without waiting for the next sync.

**Q: Do webhooks cost extra?**  
A: No, webhooks are included as part of the Antugrow integration. They provide faster updates at no additional cost.

**Q: Can I disable automatic sync?**  
A: Automatic sync is essential for keeping your data current. It cannot be disabled, but it uses minimal resources and runs in the background.

**Q: What data is synced?**  
A: Height, diameter, health status, growth data, analysis results, and care recommendations are synced from Antugrow.

**Q: Is my data safe during sync?**  
A: Yes! All sync operations use secure HTTPS connections. Your data is encrypted in transit and at rest.

**Q: What if Antugrow is down?**  
A: If Antugrow is temporarily unavailable, sync will retry automatically. Your local data remains accessible, and sync will resume when Antugrow is back online.

### Health Alerts (NEW)

**Q: How quickly do I get health alerts?**  
A: Health alerts are delivered instantly via webhooks when Antugrow detects an issue. You'll see a notification within seconds.

**Q: What should I do when I get a health alert?**  
A: Click on the notification to view details. Follow the care recommendations provided. If urgent, contact a local arborist.

**Q: Can I customize which alerts I receive?**  
A: Alert preferences will be available in a future update. Currently, you receive all important health alerts for your trees.

**Q: Are health alerts always accurate?**  
A: Antugrow AI is highly accurate, but alerts should be verified by visual inspection. Use them as early warning signs.
