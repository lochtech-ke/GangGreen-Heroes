## 🎯 Common Tasks

### For New Developers

1. **Setup Development Environment**
   - Read [Setup Instructions](./SETUP_INSTRUCTIONS.md)
   - Follow [Quick Reference](./QUICK_REFERENCE.md)
   - Review [Technical Guide](./TECHNICAL_GUIDE_NOVEMBER_19_2025.md)

2. **Understand Architecture**
   - Read [Architecture](./ARCHITECTURE.md)
   - Review [Feature Map](./FEATURE_MAP.md)
   - Study [Development Wiki](./DEVELOPMENT_WIKI.md)

3. **Start Contributing**
   - Check [Git Commit Guide](./GIT_COMMIT_GUIDE.md)
   - Review [Test Setup](../src/test/README.md)
   - Read relevant spec in `.kiro/specs/`

### For Deploying Features

1. **Database Changes**
   - Create migration in `supabase/migrations/`
   - Test locally
   - Follow [Migration Instructions](./MIGRATION_INSTRUCTIONS.md)
   - Deploy using [Apply Migration](./APPLY_MIGRATION.md)

2. **Frontend Changes**
   - Build: `npm run build`
   - Test: `npm test`
   - Deploy to Vercel

3. **Backend Changes**
   - Test edge functions locally
   - Deploy to Supabase
   - Monitor logs

### For Troubleshooting

1. **Build Errors**
   - Check [Build Summary](./BUILD_AND_TEST_SUMMARY.md)
   - Review [Build Errors Fix](../.kiro/specs/build-errors-fix/)

2. **Database Issues**
   - Check [Supabase Health](../.kiro/specs/supabase-health-check-fix/)
   - Review [Migration README](../supabase/migrations/README.md)

3. **Performance Issues**
