## Getting Started

### System Requirements

- Modern web browser (Chrome, Firefox, Safari, Edge)
- Internet connection
- MetaMask wallet (optional, for Web3 features)

1. Navigate to the platform URL
2. You'll see the landing page with:

## Authentication

### Registration

1. Click "Get Started" or "Sign Up"
2. Choose authentication method:
   - **Email/Password** (Recommended for first-time users)
   - **Web3 Wallet** (For blockchain enthusiasts)

#### Email Registration
1. Enter your email address
2. Create a strong password
3. Click "Create Account"
4. You'll be redirected to complete your profile

#### Web3 Wallet Registration
1. Click "Connect Wallet"
2. Choose MetaMask or WalletConnect
3. Approve the connection in your wallet
4. Sign the verification message
5. Complete your profile

### Login

1. Click "Sign In"
2. Choose your authentication method
3. Enter credentials or connect wallet
4. You'll be redirected to your dashboard

### Password Reset

1. Click "Forgot Password?" on login page
2. Enter your email address
3. Check your email for reset link
4. Click the link and enter new password
5. Log in with new password

## AI-Powered Tree Monitoring ⭐ NEW

### Overview

The platform now uses Antugrow AI to automatically monitor tree health, track growth, and provide care recommendations.

### Automatic Health Assessment

When you upload a tree image:
1. Image is sent to Antugrow AI
2. AI analyzes tree health
3. Results appear within minutes:
   - **Health Score** (0-100)
   - **Health Status** (Healthy, Stressed, Diseased, Dead)
   - **Disease Detection** (Yes/No)
   - **Confidence Score** (AI certainty)

### Health Status Indicators

Trees are color-coded by health:
- 🟢 **Healthy** (80-100): Thriving, no issues
- 🟡 **Stressed** (60-79): Needs attention
- 🟠 **Diseased** (40-59): Requires treatment
- 🔴 **Dead** (0-39): No longer viable

### Growth Tracking

View growth over time:
1. Navigate to tree details
2. Scroll to "Growth Chart"
3. See visual charts showing:
   - Height over time
   - Diameter growth
   - Canopy area expansion
   - Growth rate calculations

### AI-Powered Recommendations

For each tree, AI provides:
- **Care Instructions**: Watering, fertilization, pruning
- **Disease Treatment**: Specific remedies if issues detected
- **Preventive Measures**: Actions to maintain health
- **Monitoring Schedule**: When to check again

### Real-Time Notifications

You'll receive notifications for:
- ✅ Analysis completed
- ⚠️ Health score changes
- 🚨 Disease detected
- 💡 New recommendations available
- 📊 Growth milestones reached

### Viewing Analysis History

1. View tree details
2. Scroll to "Analysis History"
3. See all past analyses:
   - Date and time
   - Health scores
   - Recommendations
   - Changes over time

### Background Synchronization

The platform automatically:
- Syncs tree data every 60 minutes
- Updates health status
- Fetches new measurements
- Processes AI analysis results
- Creates notifications

### Sync Status

Check synchronization status:
1. Look for sync indicator (top right)
2. Shows:
   - Last sync time
   - Trees synced
   - Any errors
   - Next sync scheduled

3. Click "Sync Now" for manual sync

### Disease Detection Alerts

When disease is detected:
1. 🚨 Immediate notification sent
2. Health status updated to "Diseased"
3. Specific treatment recommendations provided
4. Monitoring frequency increased
5. Follow-up analysis scheduled

### Using AI Recommendations

1. View tree details
2. Scroll to "AI Recommendations"
3. Read care instructions
4. Follow suggested actions
5. Upload new image after treatment
6. AI will reassess health

### Best Practices

**For Accurate Analysis**:
- Upload clear, well-lit images
- Show full tree or affected areas
- Take photos from multiple angles
- Upload regularly (weekly recommended)
- Note any changes in description

**For Optimal Results**:
- Act on recommendations promptly
- Track your interventions
- Upload follow-up images
- Monitor health score trends
- Report unusual findings

## Troubleshooting

### Authentication Issues

**Can't log in?**
- Check email and password
- Try password reset
- Clear browser cache
- Try different browser

**Web3 wallet not connecting?**
- Ensure MetaMask is installed
- Check network (Polygon Mumbai)
- Refresh page and try again
- Check wallet is unlocked

### Profile Issues

**Profile not saving?**
- Check all required fields
- Ensure valid email format
- Try again in a few minutes
- Contact support if persists

**Image upload failing?**
- Check file size (max 5MB)
- Use JPG or PNG format
- Check internet connection
- Try different image

### Initiative Issues

**Can't create initiative?**
- Ensure you have Organization role
- Fill all required fields
- Check date format
- Verify location coordinates

**Can't join initiative?**
- Check initiative is active
- Ensure you're logged in
- Try refreshing page
- Contact initiative organizer

### Tree Registry Issues

**Tree not appearing?**
- Wait a few seconds for sync
- Refresh the page
- Check filters aren't hiding it
- Verify registration completed

**Image upload not working?**
- Check file size (max 10MB)
- Use JPG or PNG format
- Ensure stable internet
- Try again later

### AI Monitoring Issues

**Analysis taking too long?**
- Normal processing: 2-5 minutes
- Check sync status indicator
- Refresh page after 10 minutes
- Contact support if > 30 minutes

**No AI recommendations?**
- Ensure image is clear
- Check tree has Antugrow ID
- Wait for analysis to complete
- Try uploading new image

**Health status not updating?**
- Check last sync time
- Click "Sync Now" manually
- Wait for background sync
- Verify internet connection

**Sync errors?**
- Check internet connection
- Wait for automatic retry
- Try manual sync
- Contact support if persists

### General Issues

**Page not loading?**
- Check internet connection
- Clear browser cache
- Try different browser
- Disable browser extensions

**Features not working?**
- Ensure JavaScript enabled
- Update browser to latest version
- Check console for errors
- Report bug to support

### Getting Help

**Support Channels**:
- Email: support@ganggreen.org
- GitHub Issues: Report bugs
- Documentation: Check guides
- Community Forum: Ask questions

**When Reporting Issues**:
- Describe what you were doing
- Include error messages
- Note browser and version
- Attach screenshots if helpful

## Glossary

**Initiative**: A tree planting project with specific goals and timeline

**Carbon Credit**: Verified unit representing CO2 sequestered by trees

**Antugrow**: AI platform for tree monitoring and health analysis

**Health Score**: AI-calculated metric (0-100) indicating tree health

**Sync**: Process of updating tree data from Antugrow API

**Webhook**: Real-time notification from Antugrow about tree updates

**GeoJSON**: Standard format for geographic data

**PostGIS**: Database extension for geospatial queries

**Web3**: Blockchain-based authentication and transactions

**NFT**: Non-fungible token, unique digital asset
